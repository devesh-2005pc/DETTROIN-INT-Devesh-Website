# Project Overview

This project is a complete redesign of the Excellence International School website with a focus on delivering a modern, responsive, accessible, and visually engaging user experience.

Rather than copying the existing website, the design has been reimagined using modern UI/UX principles while preserving the school's purpose and essential information.

The primary objective was to create a premium educational website that demonstrates strong frontend development skills, responsive design practices, reusable React architecture, and smooth user interactions.

# Installation

Clone the repository

```bash
git clone <repository-url>
```

Navigate to the project

```bash
cd DETTROIN-INT-Devesh-Website
```

Install dependencies

```bash
npm install
```

Start the development server

```bash
npm run dev
```

Build for production

```bash
npm run build
```

Preview the production build

```bash
npm run preview
```
